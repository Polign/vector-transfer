Where will the worker run?

Use a Mac or Linux machine that can reach both databases and stay running. No inbound ports are needed. You’ll run a script there after configuring the databases.

Database settings stay in this browser until you download the script. Credentials are requested on the worker machine and held in memory. S3 Vectors uses the worker’s AWS identity.

Connect your worker

Download the script, review it, and run it within 10 minutes. It contains a single-use enrollment token.

chmod 600 setup-worker.sh
bash setup-worker.sh

Run these commands in the folder containing the downloaded script. If your worker is another machine, copy the script there first. Enter database credentials when prompted and leave the process running.

Worker not connecting?
  • Check the terminal for a credential or configuration error. Fix it locally, then restart the worker.
  • Allow outbound HTTPS to transfer.polign.com and access to both databases.
  • If the download checksum changed, generate a new script before enrollment.
Connection settings and checkpoints stay on your worker. This page can detect the worker connection, but database access is checked when a transfer runs.
